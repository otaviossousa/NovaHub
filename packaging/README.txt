NOVAHUB PARA WINDOWS
===================

Português
----------
1. Extraia todo o conteúdo do arquivo ZIP para uma pasta.
2. Execute NovaHub.exe.
3. O aplicativo continuará disponível nos ícones ocultos ao ser minimizado ou fechado.

O pacote é portátil: não precisa de instalação nem do .NET instalado separadamente.
Requer Windows 10 ou Windows 11 de 64 bits.

O Windows pode exibir um aviso do SmartScreen porque o executável ainda não possui
assinatura digital. Confirme que o arquivo veio da página oficial de Releases antes
de executá-lo.

English
-------
1. Extract the entire ZIP file to a folder.
2. Run NovaHub.exe.
3. The application remains available in the system tray when minimized or closed.

The package is portable: no installation or separate .NET runtime is required.
Requires 64-bit Windows 10 or Windows 11.

Windows may display a SmartScreen warning because the executable is not digitally
signed yet. Confirm that the file came from the official Releases page before
running it.
