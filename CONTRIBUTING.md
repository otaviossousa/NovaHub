# Como contribuir com o NovaHub

Contribuições são bem-vindas. Você pode adaptar o projeto às suas necessidades em um fork e, caso a mudança também possa ajudar outras pessoas, enviar um pull request para avaliação.

## Informar problemas ou sugerir melhorias

Antes de abrir uma issue:

1. verifique se já existe uma issue semelhante;
2. informe a versão do Windows e a versão do NovaHub;
3. descreva o modelo do controle e o modo de conexão utilizado;
4. explique o comportamento esperado e o que realmente aconteceu;
5. revise capturas e relatórios antes de publicá-los para não expor identificadores do computador.

## Enviar alterações

1. Faça um fork do repositório.
2. Crie uma branch específica para a mudança.
3. Implemente a alteração mantendo o comportamento existente.
4. Execute `./build.ps1` para compilar e rodar as verificações.
5. Abra um pull request descrevendo o problema resolvido e a solução adotada.

Ao alterar a interface, mantenha os textos em português e inglês. Mudanças relacionadas à identificação de controles devem evitar assumir que interfaces diferentes representam controles físicos diferentes sem evidência confiável.

Pull requests podem ser discutidos e ajustados antes da incorporação. O envio de uma contribuição não garante que ela será incluída, mas toda sugestão será considerada de acordo com o objetivo e a simplicidade do projeto.
